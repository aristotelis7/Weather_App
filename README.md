Η εφαρμογή Weather Map Greece είναι ένα διαδραστικό γραφικό περιβάλλον (GUI) που εμφανίζει έναν χάρτη της Ελλάδας και επιτρέπει στον χρήστη να κάνει κλικ σε πόλεις για να δει:

• Τρέχουσα θερμοκρασία
• Ταχύτητα ανέμου
• Εικονίδιο καιρού (ήλιος, σύννεφα, βροχή, άνεμος)

Η εφαρμογή χρησιμοποιεί πραγματικά δεδομένα καιρού μέσω του Open‑Meteo API.

ΑΡΧΕΙΑ ΤΟΥ PROJECT
1. main.py
Το κύριο πρόγραμμα.

Φορτώνει τον χάρτη.

Σχεδιάζει τις πόλεις.

Εντοπίζει κλικ του χρήστη.

Εμφανίζει θερμοκρασία, άνεμο και εικονίδιο καιρού.

Δημιουργεί γράφημα 7 ημερών.

2. weather_bridge2.py
Ενδιάμεσο αρχείο (bridge).

Περιέχει τις συντεταγμένες των πόλεων.

Καλεί απευθείας το Open‑Meteo API.

Επιστρέφει θερμοκρασία, άνεμο και 7ήμερη πρόγνωση.

3. icons/
Φάκελος με PNG εικονίδια καιρού:
sun.png, cloud.png, rain.png, wind.png

4. greece_map.png
Ο χάρτης της Ελλάδας.
Η εφαρμογή τον κάνει resize σε 600×625 px.

ΠΩΣ ΛΕΙΤΟΥΡΓΕΙ Η ΕΦΑΡΜΟΓΗ
Ο χρήστης ανοίγει το πρόγραμμα.

Εμφανίζεται ο χάρτης της Ελλάδας.

Πάνω στον χάρτη υπάρχουν κόκκινες κουκκίδες για κάθε πόλη.

Ο χρήστης κάνει κλικ σε μια πόλη.

Η εφαρμογή:
• εντοπίζει ποια πόλη είναι κοντά στο κλικ
• ζητάει δεδομένα καιρού από το weather_bridge
• το weather_bridge καλεί το Open‑Meteo API

Τα δεδομένα επιστρέφουν στο GUI.

Το GUI εμφανίζει:
• θερμοκρασία
• άνεμο
• εικονίδιο καιρού πάνω από την πόλη
• γράφημα 7 ημερών

ΠΩΣ ΓΙΝΕΤΑΙ Η ΜΕΤΑΤΡΟΠΗ LAT/LON → PIXELS
Ο χάρτης είναι εικόνα, όχι πραγματικός γεωγραφικός χάρτης.
Άρα χρειάζεται αναλογική μετατροπή:

Code
x = (lon - MIN_LON) / (MAX_LON - MIN_LON) * MAP_WIDTH
y = (MAX_LAT - lat) / (MAX_LAT - MIN_LAT) * MAP_HEIGHT
Έτσι κάθε πόλη τοποθετείται σωστά πάνω στον χάρτη.

ΠΩΣ ΕΠΙΛΕΓΕΤΑΙ ΤΟ ΕΙΚΟΝΙΔΙΟ ΚΑΙΡΟΥ
Η συνάρτηση pick_icon(temp, wind):

• Αν ο άνεμος > 35 km/h → wind.png
• Αν η θερμοκρασία > 25°C → sun.png
• Αν η θερμοκρασία < 15°C → rain.png
• Αλλιώς → cloud.png
