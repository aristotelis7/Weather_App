 Τεχνολογίες που χρησιμοποιήθηκαν

2.1 Tkinter
Η Tkinter είναι η βασική βιβλιοθήκη της Python για δημιουργία γραφικών διεπαφών (GUI). Χρησιμοποιείται για:
•	Το κύριο παράθυρο της εφαρμογής
•	Τον καμβά (Canvas) όπου εμφανίζεται ο χάρτης
•	Τα labels και τα widgets
•	Τον χειρισμό των events (π.χ. κλικ του χρήστη)

2.2 Pillow (PIL)
Χρησιμοποιείται για:
•	Φόρτωση εικόνων (χάρτης και icons)
•	Μετατροπή εικόνων σε μορφή κατάλληλη για Tkinter (ImageTk.PhotoImage)

2.3 Matplotlib
Χρησιμοποιείται για:
•	Δημιουργία γραφημάτων θερμοκρασίας και ανέμου
•	Ενσωμάτωση των γραφημάτων μέσα στο GUI μέσω FigureCanvasTkAgg

2.4 weather_bridge
Είναι βοηθητικό module που αναλαμβάνει:
•	Κλήση του Open Meteo API
•	Λήψη τρέχοντος καιρού και 7ήμερης πρόγνωσης
•	Επιστροφή δεδομένων σε μορφή λεξικού (dictionary)

3. Περιγραφή Λειτουργίας της Εφαρμογής
Η εφαρμογή εμφανίζει έναν χάρτη της Ελλάδας. Πάνω στον χάρτη έχουν τοποθετηθεί πέντε πόλεις, με βάση τις γεωγραφικές τους συντεταγμένες. Ο χρήστης μπορεί να κάνει κλικ πάνω σε μια πόλη και η εφαρμογή:
1.	Αναγνωρίζει ποια πόλη επιλέχθηκε
2.	Ζητά δεδομένα καιρού από το weather_bridge
3.	Εμφανίζει θερμοκρασία και άνεμο
4.	Παρουσιάζει γράφημα 7 ημερών
Το γράφημα περιλαμβάνει:
•	Κόκκινη γραμμή για θερμοκρασία
•	Μπλε γραμμή για άνεμο

4. Ανάλυση Κώδικα

4.1 Εισαγωγή βιβλιοθηκών
Γίνεται εισαγωγή όλων των απαραίτητων βιβλιοθηκών. Το Matplotlib ρυθμίζεται να χρησιμοποιεί το backend TkAgg, ώστε να μπορεί να εμφανίζει γραφήματα μέσα στο Tkinter.

4.2 Ρυθμίσεις χάρτη
Ορίζονται:
•	Το μέγεθος του χάρτη
•	Τα γεωγραφικά όρια της Ελλάδας
•	Συνάρτηση μετατροπής γεωγραφικών συντεταγμένων σε pixel
Αυτό επιτρέπει την ακριβή τοποθέτηση των πόλεων πάνω στην εικόνα.

4.3 Λίστα πόλεων
Οι πόλεις αποθηκεύονται σε λίστα μαζί με τις συντεταγμένες τους. Οι συντεταγμένες μετατρέπονται σε pixel και αποθηκεύονται σε νέα δομή δεδομένων.

4.4 Κλάση WeatherApp
Η κλάση αυτή περιέχει όλη τη λειτουργικότητα της εφαρμογής.

4.4.1 Constructor
•	Δημιουργεί το παράθυρο
•	Φορτώνει τον χάρτη
•	Τοποθετεί τις πόλεις
•	Φορτώνει τα icons
•	Συνδέει το event του κλικ
•	Προσθέτει label για εμφάνιση καιρού

4.4.2 on_click()
Ανιχνεύει αν ο χρήστης έκανε κλικ κοντά σε κάποια πόλη. Αν ναι, καλεί τη show_weather().

4.4.3 show_weather()
•	Καλεί το weather_bridge για να πάρει δεδομένα
•	Εμφανίζει θερμοκρασία και άνεμο
•	Επιλέγει και εμφανίζει το κατάλληλο icon
•	Καλεί τη show_graph() για το γράφημα

4.4.4 show_graph()
Δημιουργεί γράφημα 7 ημερών:
•	Θερμοκρασία → κόκκινη γραμμή
•	Άνεμος → μπλε γραμμή
Το γράφημα ενσωματώνεται στο GUI μέσω Matplotlib.

5. Γραφικό Περιβάλλον (GUI)
Το GUI είναι απλό και λειτουργικό:
•	Μεγάλος χάρτης στο κέντρο
•	Πόλεις σημειωμένες με κόκκινο
•	Πληροφορίες καιρού κάτω από τον χάρτη
•	Γράφημα στο κάτω μέρος
Η εφαρμογή είναι εύχρηστη και κατάλληλη για εκπαιδευτική χρήση.

6. Συμπεράσματα
Η εφαρμογή Weather Map Greece αποτελεί ένα ολοκληρωμένο παράδειγμα συνδυασμού:
•	Γραφικών διεπαφών (Tkinter)
•	Επεξεργασίας εικόνας (Pillow)
•	Οπτικοποίησης δεδομένων (Matplotlib)
•	Επικοινωνίας με API (weather_bridge)

Η υλοποίηση είναι καθαρή,  μπορεί εύκολα να επεκταθεί με:
•	Περισσότερες πόλεις
•	Περισσότερα εικονίδια καιρού
•	Χάρτες υψηλότερης ανάλυσης
•	Πρόγνωση περισσότερων ημερών
